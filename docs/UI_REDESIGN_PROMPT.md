## УТВЕРЖДЁННАЯ ДИЗАЙН-СПЕКА

### Тема
- **Light-only.** Тёмная тема и переключатель удаляются полностью.
- Фон белый `#FFFFFF` / слегка серые поверхности, текст чёрный/почти чёрный.

### Типографика («программистская»)
- **JetBrains Mono** (уже подключён через `next/font/google` в `src/app/layout.tsx`) —
  заголовки (h1–h4), цифры/метрики/счётчики, бейджи, кнопки, ID, табличные числовые
  колонки, лейблы-«технические» подписи (стиль `TOKENS_USED`).
- **Space Grotesk** — основной текст: параграфы, описания, формы, контент таблиц.
  Подключить через `next/font/google`, заменить Inter И Playfair Display (серифный
  заголовочный шрифт текущего F0-дизайна — удаляется вместе с `--font-heading`,
  grep по `font-heading` и `Playfair`). Дублирующие `@font-face` с gstatic в начале
  `globals.css` (грузят шрифты ВТОРОЙ раз при самохостинге через next/font — баг) — убрать.
- Кириллица обязательна: у Space Grotesk **нет кириллицы** — проверь это и выбери
  решение: (а) подмешать `subsets` с fallback на системный гротеск для кириллицы,
  (б) взять технический гротеск С кириллицей похожего характера — кандидаты:
  **IBM Plex Sans**, **Onest**, **Unbounded** (для заголовков), **Manrope**.
  Рекомендуемый дефолт: IBM Plex Sans (родная пара к Plex Mono, есть кириллица,
  «инженерный» характер). Зафиксируй выбор в плане с обоснованием.
- Моноширинные цифры в таблицах: `font-variant-numeric: tabular-nums` для числовых колонок.

### Палитра (light)
| Токен | Значение | Использование |
|---|---|---|
| `--background` | `#FFFFFF` | основной фон |
| `--bg-secondary` | `#F7F7F8` | карточки-подложки, сайдбар |
| `--bg-hover` | `#EFEFF1` | ховеры строк/пунктов |
| `--foreground` / `--text-primary` | `#0A0A0B` | основной текст |
| `--text-secondary` | `#52525B` | вторичный текст |
| `--text-muted` | `#A1A1AA` | подписи |
| `--border` | `#E4E4E7` | границы |
| **Primary (кислотный зелёный)** | градиент `#9FFF5B → #5BFF8F` (135deg), текст на нём `#0A0A0B` (ЧЁРНЫЙ — белый на кислотном не пройдёт контраст) | primary-кнопки, CTA, активные состояния |
| `--primary` (плоский, для ring/ссылок/иконок) | `#65D926` или темнее — ПРОВЕРЬ контраст ≥3:1 на белом для UI-элементов, для текста ссылок нужен ≥4.5:1 (возможно `#3F9E1A`) | focus ring, активные иконки, ссылки |
| **Destructive (красный)** | градиент `#FF4D4D → #C41E3A`, текст белый | удаление, опасные действия |
| `--destructive` (плоский) | `#DC2626` | текст ошибок, бордеры ошибок |
| **Бордовый (вторичный акцент)** | `#6E1423` (+ светлый тон `#9A2540` для градиентных пар `#9A2540 → #6E1423`) | вторичные акцентные кнопки/действия, ховеры ссылок, выделенные бейджи, линии графиков |
| `--success` | оставить зелёную семантику, но согласовать с кислотным primary (success-бейджи НЕ должны выглядеть как CTA — возьми спокойный `#16A34A`) | статусы |
| `--warning` | `#D97706` | статусы |
| `--info` | `#2563EB` | статусы |

- Градиенты — фирменная фишка для **акцентных элементов**: primary/destructive кнопки,
  активный пункт сайдбара (тонкая полоска/подсветка), прогресс-бары использования,
  возможно рамки выделенных карточек (gradient border). НЕ красить градиентом текст
  и большие поверхности.
- Чарты (recharts, 6 цветов `--chart-1..6`): пересобрать палитру вокруг
  зелёный/бордовый/чёрный + 2-3 нейтрально-технических (предложи конкретные hex).

### Анимации (источник — https://21st.dev/community/components)
- 21st.dev — реестр shadcn-совместимых компонентов; установка:
  `npx shadcn@latest add "<URL компонента с 21st.dev>"` (на странице каждого компонента
  есть готовая команда). Компоненты ставятся в `src/shared/ui` (см. `components.json`).
- Большинство анимированных компонентов тянут **framer-motion (`motion`)** — его в
  проекте НЕТ. Решение: добавить `motion` одной зависимостью, тяжёлые анимированные
  блоки подключать через `next/dynamic`, и обязательно уважать `prefers-reduced-motion`.
- Где искать кандидатов на сайте: категории Buttons, Cards, Backgrounds, Text,
  Number/Counter, Loaders. Выбирай компоненты с малым кодом и без лишних зависимостей;
  каждый адаптируй под токены проекта (никаких захардкоженных цветов из примеров).
