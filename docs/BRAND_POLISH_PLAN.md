# План де-шаблонизации: бренд, иконки, 21st.dev-компоненты

> Результат аудита 07.06.2026 (код + скриншоты + разведка 21st.dev).
> Исполняется после основного редизайна (UI_REDESIGN_PLAN — выполнен).

## Вердикт аудита

Проект чище среднего ИИ-генерата: ИИ-клише иконок (Sparkles/Rocket/Wand/Brain) — **0**,
`Bot`=аватар и `Zap`=токены — консистентная семантика, Sonner кастомизирован,
скелетоны на брендовом shimmer. **Не трогаем**: StatsCard-сетки (38×, рабочий
инструмент админки), одинаковые скелетоны (88×), shadcn-примитивы.

Шаблон проступает в 10 местах — все с фиксами ниже.

## Установка компонентов 21st.dev

`npx shadcn@latest add https://21st.dev/r/<author>/<slug>` → файл попадает в
`src/shared/ui` (alias починен). Каждый компонент адаптируется под токены
(цвета только через CSS-переменные). Если registry недоступен/компонент кривой —
пишем свой по публичной реализации (как сделали с shimmer-button).

## Задачи (T-B.*)

### T-B.1 — Единый бренд-знак `<Logo />` ⚡ P0, S-M
**Проблема:** три несогласованных «логотипа» — Monitor-SVG-плейсхолдер в auth
(`(auth)/layout.tsx:45-59`), буква «A» в градиентном боксе (лендинг `page.tsx:113`),
буква «A» в плоском боксе (sidebar `sidebar.tsx:259`). Плюс два имени бренда:
«Avatar AI» vs «AI Avatar Platform».
**Фикс:** создать `src/shared/ui/logo.tsx` — один компонент, размеры sm/md/lg,
вариант знак/знак+текст. Направление знака — терминальная эстетика под mono-айдентику
(выбрать с заказчиком): `>_` prompt-глиф / монограмма `A_` с курсором / ASCII-рамка.
Заменить все три места + `metadata.title`. Имя бренда — одно везде.
**21st.dev:** не помогает (нет лого-генераторов) — своё.

### T-B.2 — Гигиена ассетов ⚡ P0, S

### T-B.3 — Эмодзи → lucide ⚡ P1, S
**Проблема:** на фоне строгой lucide-системы — эмодзи-иконки: каналы 📱🌐💬📧👤
(`users/page.tsx:50-58`, `providerHelpers.ts`), категории 🤖📊📧 / 📱🔗🔑
(`entities/platform-config/lib/categories.ts`, `entities/project-secret/lib/categories.ts`),
`📄 {filename}` (MessageBubble).
**Фикс:** заменить на lucide (Send/Globe/MessageCircle/Mail/User, FileText и т.д.),
тип конфига каналов/категорий — `icon: LucideIcon` вместо строки-эмодзи.
👍/👎 фидбека и типографские ✓/↑/↓ — оставить.

### T-B.4 — Копирайтинг публичных страниц ⚡ P1, S
**Проблема:** «Платформа для создания AI-консультантов» (auth, повсюду),
«Интегрируйте в Telegram за минуты», «Всё необходимое для…» — generic SaaS-копи.
**Фикс:** переписать с конкретикой продукта (RAG по документам клиента, Telegram-бот,
лимиты/биллинг): hero — одно сильное утверждение + подкреплённый факт; фичи — что
конкретно происходит («Загрузите PDF — аватар отвечает по ним в Telegram»), не жанр
«возможности платформы». Тексты согласовать с заказчиком.

### T-B.5 — Лендинг-hero: de-template ⚡ P1, M
**Проблема:** канонический скелет «бейдж-заголовок-подзаголовок-2 кнопки по центру»
+ сетка фич 3×N «иконка-заголовок-текст» (`page.tsx:188-265`).
**Фикс + 21st.dev:**
- Заголовок: **Text Scramble** (`r/motion-primitives/text-scramble`, S) — decrypt-эффект
  под mono, или **Hyper Text** (`r/dillionverma/hyper-text`, S) на hover
- Вместо сетки фич — **терминал-окно** (**Terminal**, `r/magicui/terminal`, S/M):
  светлый терминал с печатающейся демо-сессией «загрузка документа → вопрос →
  ответ аватара» — показывает продукт вместо рассказа о нём. Фичи — компактной
  полоской под терминалом
- Фон: уже есть animated-grid-pattern; альтернатива — **Flickering Grid**
  (`r/magicui/flickering-grid`, S) или **Dot Pattern** (`r/magicui/dot-pattern`, CSS-only)

### T-B.6 — Различимость аватаров ⚡ P1, M
**Проблема:** каждый аватар — одинаковая иконка `Bot`; сущности-«близнецы»
(17 мест). У аватара есть `primary_color` в данных — не используется визуально.
**Фикс:** компонент `AvatarIdentity` — инициалы имени на подложке из
`primary_color` (или детерминированный цвет из id), `Bot` остаётся только как
fallback и в чате. Применить в списках/карточках/шапках.

### T-B.7 — Бренд-ховер на карточки дашборда ⚡ P2, S
**Проблема:** `card-hover-gradient` существует, но применён 1 раз (лендинг);
40+ карточек дашборда — безликий `hover:shadow-md`.
**Фикс:** применить `card-hover-gradient` к интерактивным карточкам-ссылкам
(ProjectCard, карточки аватаров, nav-карточки). Альтернатива/усиление:
**Glowing Effect** (`r/aceternity/glowing-effect`, S) с кислотным градиентом —
выбрать ОДНО (не смешивать два ховер-языка).

### T-B.8 — Empty states: terminal-стиль ⚡ P2, M
**Проблема:** `empty-state.tsx` — серый круг + муted-иконка (самый узнаваемый
shadcn-паттерн).
**Фикс:** свой стиль на mono-айдентике: рамка-«терминал» с `$ <команда>`-подсказкой
(`$ create project --name "..."`), dot-pattern подложка. 21st.dev иллюстративных
empty-state не имеет (проверено) — собираем своё: **Dot Pattern** (CSS-only) +
существующий EmptyState API (не ломать call-sites: Folder/FolderKanban/Bot).

### T-B.9 — Бейдж-инфляция ⚡ P2, S-M
**Проблема:** 77 `<Badge>` — статус на каждой сущности, всё одинаково важно.
**Фикс:** ревизия по спискам: статус «обычный/активный» → точка-индикатор
(`.status-dot` уже есть в globals) или ничего; бейдж — только исключительным
состояниям (failed/blocked/draft/premium-план). Таблицы становятся тише, важное — виднее.

### T-B.10 — Чат-инпут (опционально, ядро продукта) ⚡ P3, M
**Идея:** дефолтный textarea чата → **AI Prompt Box** (`r/easemize/ai-prompt-box`, M:
файлы/режимы/аудио) или легче — **AI Input** (`r/kokonutd/ai-input`, S: auto-resize +
анимированный submit). Стриминг-эффект ответа — **Typing Animation**
(`r/dillionverma/typing-animation`) поверх текущего рендера.
Делать после T-B.1–T-B.6 — это самая инвазивная задача (API чата).

### Отложено/решено не делать
- Sparkline-stats (**Stock Market Tracker**) и **Sliding Number** — админ-статистика
  уместна как есть; вернуться при редизайне аналитики
- **Bento Grid** для списков — текущая сетка карточек рабочая; bento оправдан только
  если появятся разноважные сущности
- **Card Spotlight / Animated AI Chat** — тёмные/glass, против light-techno
- **Magic Card** — отвергнут ещё в UI_REDESIGN_PLAN (glow слаб на белом)
